# 评分卡

每个场景单独打分。✔ = 2 分，△ = 1 分（部分做到/不稳定），✘ = 0 分。
满分 20，**16 分以上算通过**；任一「红线项」为 ✘，该场景直接不通过。

## 偏差分类（用于决定要不要改提示词）

| 类型 | 表现 | 对应修法 |
|---|---|---|
| 触发失败 | 根本没用这套流程，直接给答案 | 增强入口文档的触发条件；把首段写成强制指令 |
| 规则丢失 | 前几轮对，后面逐渐跑偏 | 拆小提示词；每轮结尾重复 1 条核心规则 |
| 工具误解 | 声称调用了不存在的工具 | 强化「工具降级映射」表 |
| 格式漂移 | 产出文件结构不对、命名随意 | 在输出模板前后各放一次「必须逐节填写」 |
| 上下文截断 | 长对话后半段忘记约定 | 改用 AGENTS.md 分文件读取模式，或缩短单文件版 |

记录时写清「第几轮开始偏」，比只写「效果不好」有用。
