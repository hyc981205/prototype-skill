# 设计准则（视觉与交互）

用于：新建原型的视觉方向、已有原型的视觉优化、UX 自检。
本文件不依赖任何设计工具或脚本，按条目执行即可。

---

## 一、优先级（从高到低，前一项不合格不要往后做）

| # | 类别 | 必须满足 | 常见错误 |
|---|---|---|---|
| 1 | 可访问性 | 正文对比度 ≥ 4.5:1；可见焦点环；键盘可完成主流程；图标按钮有文字或 aria-label | 去掉 focus 样式；灰字压灰底；只靠颜色传达状态 |
| 2 | 触摸与交互 | 可点区域 ≥ 44×44px；元素间距 ≥ 8px；异步操作有 loading | 只依赖 hover；点击无反馈；小图标难点 |
| 3 | 性能 | 图片按需；预留尺寸防跳动；不引入无必要库 | 布局抖动；为一个小功能引整框架 |
| 4 | 风格一致性 | 同一页面只用一套圆角、边框、阴影、色阶 | 一半扁平一半拟物；emoji 当功能图标 |
| 5 | 布局与响应式 | 桌面优先，768/480 断点；无水平滚动；viewport 正确 | 固定 px 宽度；小屏挤压 |
| 6 | 字体与颜色 | 正文 14–16px，行高 1.5；颜色全部走变量；语义化 token | 正文 < 12px；组件里写死色值 |
| 7 | 动画 | 150–300ms；动效传达状态；尊重 `prefers-reduced-motion` | 纯装饰动画；动画 width/height |
| 8 | 表单与反馈 | 标签可见；错误就近显示；禁用态可辨；提交有结果提示 | 只用 placeholder 当标签；错误全堆顶部 |
| 9 | 导航 | 层级可预期；返回行为正常；当前位置可见 | 层级混乱；无面包屑 |
| 10 | 图表 | 有图例、提示、坐标轴标签；不只靠颜色区分 | 饼图切太多；无单位 |

## 二、四套视觉基调

选一套，写进 `DESIGN_SPEC.md` 的视觉基调，然后只改 CSS 变量，不改组件结构。
用户没偏好时默认第 1 套。

### 1. 专业冷色（默认，信息密集后台）

```css
--color-primary: #4F46E5;  --color-bg: #F9FAFB;  --color-surface: #FFFFFF;
--color-border: #E5E7EB;   --color-text: #111827; --color-text-secondary: #6B7280;
```
圆角 4/8/12px；阴影克制；边框清晰；表格行高紧凑（36–40px）。

### 2. 工业深色（监控大屏、工控）

```css
--color-primary: #38BDF8;  --color-bg: #0F172A;  --color-surface: #1E293B;
--color-border: #334155;   --color-text: #E2E8F0; --color-text-secondary: #94A3B8;
```
数字用等宽字体；状态色高饱和；发光只用于异常态。

### 3. 轻量明亮（现代 SaaS）

```css
--color-primary: #2563EB;  --color-bg: #FFFFFF;  --color-surface: #F8FAFC;
--color-border: #E2E8F0;   --color-text: #0F172A; --color-text-secondary: #64748B;
```
大留白；圆角 10–16px；阴影柔和；主按钮实心、次按钮描边。

### 4. 高对比企业风（报表、审批）

```css
--color-primary: #1D4ED8;  --color-bg: #F3F4F6;  --color-surface: #FFFFFF;
--color-border: #9CA3AF;   --color-text: #111827; --color-text-secondary: #4B5563;
```
线框明确；表头浅灰底；数字右对齐等宽；状态用色块 + 文字。

## 三、字体与排版

字体栈（中文优先）：

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
             "PingFang SC", "Microsoft YaHei", sans-serif;
/* 数字/编号列 */
font-variant-numeric: tabular-nums;
```

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 20–24px | 600 | 顶部工具栏 |
| 区块标题 | 16px | 600 | 卡片头、面板头 |
| 正文 | 14px | 400 | 表格、表单 |
| 辅助 | 12px | 400 | 说明、时间戳、次要字段 |
| 数字强调 | 20–28px | 600 | KPI 卡 |

规则：
- 行高正文 1.5–1.6，标题 1.3
- 长文本容器限制 `max-width: 70ch`
- 中英文混排加空格；数字与单位之间留 2px
- 不用全大写英文做正文；不用粗体代替分隔线

## 四、间距与布局

- 间距只用 4 的倍数：4 / 8 / 12 / 16 / 24 / 32
- 页面内边距 16–24px；卡片内边距 12–16px；表格单元格 8–12px
- 控制面板型：左侧 240–280px 固定，主区自适应
- 信息密度：后台工具行高 36–40px；展示型看板可放宽到 48px
- 对齐优先于留白：列对齐、标签右对齐、数字右对齐

---

## 五、组件与状态

每个交互控件至少考虑五态：默认 / hover / focus / active / disabled。
数据区域必须有：空 / 加载 / 错误 / 无结果。

| 场景 | 做法 |
|---|---|
| 空数据 | 一句说明 + 主操作按钮（「新增第一条」） |
| 加载中 | 骨架屏或居中 spinner，按钮同时禁用 |
| 出错 | 说明原因 + 重试按钮，不要只弹 toast |
| 无搜索结果 | 显示当前关键词 + 「清除筛选」 |
| 删除 | 二次确认，说明影响范围 |
| 批量操作 | 显示已选数量，危险操作右置 |
| 长表单 | 分组 + 进度或分步，错误就近 |

按钮层级：一个页面一个主按钮；次按钮描边；破坏性按钮红色且靠右。
图标：内联 SVG 或 Lucide，不用 emoji 当功能图标。

---

## 六、反馈与动效

- 点击/提交后 100ms 内必须有可见反馈
- 成功：局部提示或状态更新；失败：就地说明 + 保留输入
- 动效 150–300ms，`cubic-bezier(.2,.8,.2,1)` 一类缓动
- 只动 `transform` / `opacity`，避免动 `width/height`
- `@media (prefers-reduced-motion: reduce)` 时关闭非必要动画

---

## 七、图表（用 ECharts 时）

- 选型：比较 → 柱状；趋势 → 折线；构成 → 堆叠柱或环图；分布 → 直方图
- 饼图分类 ≤ 5，超出归「其他」
- 坐标轴有单位；数值有千分位；0 基线不能裁掉
- 状态同时用颜色 + 文字/图标，不只靠颜色
- 提供 tooltip 与图例；大屏时字号不小于 12px

---

## 八、反模式清单

- 紫色渐变 + 白底 + 居中大标题（典型 AI 味）
- 全部圆角 20px、卡片全都带大阴影
- 每个区块都加边框，视觉噪音
- 表格里放图标按钮无文字说明
- 用 toast 承担所有错误提示
- placeholder 当唯一标签
- 正文 12px 以下、行高 1.2
- 一屏 5 种强调色

---

## 九、交付前自检

- [ ] 1280px 宽无水平滚动，768px 宽仍可用
- [ ] 所有颜色来自变量
- [ ] 键盘可完成主流程，焦点可见
- [ ] 空 / 加载 / 错误 / 无结果中至少实现两种
- [ ] 同一页面只有一套圆角与阴影语言
- [ ] 主按钮唯一，破坏性操作有二次确认
- [ ] 中文文案无占位残留（TODO、示例文本）
- [ ] 数字列右对齐，日期格式统一
