# 原型模板 — 使用说明

四个文件是空白原型的标准基线，每个新原型从这里派生，保证跨原型风格一致。

| 文件 | 内容 |
|---|---|
| `index.html` | 三栏骨架：工具栏 + 左面板 + 主面板；已设 UTF-8 / viewport |
| `style.css` | CSS reset + 完整变量主题 + 按钮/表单/卡片/空状态组件类 |
| `script.js` | IIFE 空骨架，五个注释分区 |
| `CODE_ARCHITECTURE.md` | 架构文档模板，编码后按实际填写 |

## 用法

1. 新建目录并复制四个文件（不要连本说明一起拷）：
   ```bash
   mkdir -p prototypes/你的工具名
   cp 原型模板/index.html 原型模板/style.css 原型模板/script.js 原型模板/CODE_ARCHITECTURE.md prototypes/你的工具名/
   ```
2. 把 `index.html` 的 `<title>` 和 `.toolbar-title` 改成原型名。
3. 按 `知识库/04-技术规范.md` 的流程开发。
4. 开发完成后，把 `CODE_ARCHITECTURE.md` 改成实际结构（不是保留模板内容）。
5. 补充 `NOTES.md`（创建日期/目的/场景/数据）和 `REQUIREMENTS.md`（需求记录）。

## 注意

- 不要建子目录放页面文件，全部平铺
- 需要图片/图标时新建 `assets/`
- 不要引入构建工具、`package.json`
- 模板里的 CSS 变量不要删，改值即可
